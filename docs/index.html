Step 1 — Trust the certificate

Synchro is signed with our own self-signed certificate rather than a purchased one. Windows will refuse to install the app until that certificate is trusted, so do this first — skipping it is what produces the vague “this app package is not signed with a trusted certificate” failure.

  1. Download the certificate above, then find it in your Downloads folder.
  2. Right-click SynchroInstall_0.0.37.0_x86_x64.cer and choose Install Certificate.
  3. For Store Location pick Local Machine, then Next. Windows will ask for administrator permission — approve it.
  4. Choose Place all certificates in the following store, click Browse, and select Trusted People. Not Personal, and not Trusted Root — Windows only accepts Trusted People here.
  5. Click Next, then Finish. You should see “The import was successful.”

This is a one-time step per computer. Every Synchro release is signed with the same certificate, so later updates install without repeating it.

Rather do it from PowerShell?

Open PowerShell as Administrator (right-click Start → Terminal (Admin)) and run:

Import-Certificate -FilePath "$HOME\Downloads\SynchroInstall_0.0.37.0_x86_x64.cer" -CertStoreLocation Cert:\LocalMachine\TrustedPeople

Step 2 — Install Synchro

  1. Download the installer above. It is a large file — give it time on a slow connection.
  2. Double-click SynchroInstall_0.0.37.0_x86_x64.msixbundle.
  3. In the App Installer window that opens, click Install. If you already have Synchro, the button reads Update and your settings are kept.
The installer says a required component is missing

The bundle expects the Windows App Runtime and VC++ libraries, which Windows normally fetches on its own. On a machine without Microsoft Store access it cannot, and the install stops. Either use the App Installer manifest, which pulls these in automatically, or install them by hand first:

  • Microsoft.VCLibs.x64.14.00.appx — 875.6 KB
  • Microsoft.VCLibs.x64.14.00.Desktop.appx — 6.4 MB
  • Microsoft.VCLibs.x86.14.00.appx — 740.8 KB
  • Microsoft.VCLibs.x86.14.00.Desktop.appx — 5.8 MB
  • Microsoft.WindowsAppRuntime.2.x64.msix — 43.1 MB
  • Microsoft.WindowsAppRuntime.2.x86.msix — 21.8 MB

Install the ones matching your Windows architecture — x64 on any current machine — then run the installer again.
